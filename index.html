Pretty Drafter

A browser-based whiteboard for teaching, studying and explaining ideas — built for pen input and geometry.
GitHub · MIT License

Tools

DCycle drawing tools (pencil, highlighter, line, text)
ECycle editing tools (eraser, hand, selection)
GCycle geometry shapes
SCycle solids (cube, prisms, pyramids)
FCycle function graphs (parabola, hyperbola, sine)
CCycle colors
TCycle thickness (for text: light / regular / bold)
BCycle backgrounds

Editing

EnterFinish the current shape, image, selection or text
XCancel the current shape or image; put a selection back where it was
DeleteDelete the current selection or image
ShiftHold for angle snapping (line), a square (rectangle), an equilateral triangle, or a square frame for solids and graphs (a true cube)
Ctrl + ZUndo the last drawing (except for eraser)
Ctrl + VInsert an image from the clipboard
Shift + EnterNew line while typing text

Layers

1–3Switch to a layer
Shift + 1–3Toggle layer visibility
Ctrl + 1–3Clear a layer
